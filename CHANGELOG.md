## [0.1.0]
### Added
- Toolbar dropdown to select the active environment (new and classic UI).
- Settings page: environments, common variables, per-module overrides,
  run configuration types, secret rows stored in the IDE password safe.
- Injection of the selected environment into Java-based run configurations.
- Import of a folder of `.env` files.
- Optional confirmation before running against an environment.
